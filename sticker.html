Sticker Maker

Make a Discord sticker from a GIF or PNG. Everything runs in your browser, so the file is never uploaded.

Sticker type

    To save it, right-click the preview (or long-press on a phone) and choose save image. Save it as sticker.png.

    Discord's limits: 320 × 320 px, under 512 KB, and animated stickers up to 5 seconds. Discord can change these, so check its sticker guidelines.
