Rename files

Give any file a new name. Works with pictures, GIFs, videos, PDFs and anything else. The file itself stays the same.

Apply to all files (optional)

Your files are never uploaded. Each file is saved to your device with the new name when you press Save.

Your browser may ask you to allow several downloads when you press Save all.
